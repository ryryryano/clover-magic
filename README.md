# clover-magic

Helpful tips and tricks for using Clover. Each one is in its own folder, with a README that explains the problem, the fix and how to check it worked, plus any files you need.

## Tips

| Tip | What it does |
| --- | --- |
| [disable-clover-plugin](disable-clover-plugin/) | Turn off the Clover Security - Kura plugin in Claude Code for one folder and everything under it. |

## Adding a tip

1. Create a folder with a short, descriptive name.
2. Add a `README.md` covering what the tip is for, how to set it up, how to check it works, and any limits.
3. Put any files it needs in the same folder.
4. Add a row to the table above.
